### 교훈
- **자동화의 판정 기준도 설계 대상이다.** "전부 PASS"가 아닌 제품에서는, 실패를 알려진 결함과 새 실패로 나누는 기준이 있어야 CI가 의미를 가진다.
- **측정 도구가 측정 대상을 바꿀 수 있다.** 부하 발생기 실행 방식이 인스턴스 수를 되돌린 것처럼, 결과가 이상하면 측정 환경부터 의심한다 (`instance_counts`가 그 단서였다).
- **증거끼리 맞춰 본다.** 주입한 오류 수 = 검출 수, 부하 구간 ⊃ 중복 확인 구간처럼 서로 다른 출처의 숫자를 대조해 결과를 믿을 수 있게 했다.
