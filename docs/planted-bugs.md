# 일부러 심은 버그 목록

결함 리포트(TC-002 · 05)를 보여주기 위해 v1.0에 **의도적으로** 넣은 버그다.
몰래 넣지 않는다는 원칙에 따라 위치와 의도를 여기에 적고, 코드에도 `PLANTED BUG-xxx` 주석을 달았다.
테스트는 이 문서를 보지 않은 것처럼 명세(`01-requirements.md`)만 보고 수행한다.

| ID | 위반 규칙 | 위치 | 버그 내용 | 의도 (어떤 테스트로 잡히나) | 결함 리포트 |
|---|---|---|---|---|---|
| BUG-001 | R-02 | `app/processor.py` `judge_round()` | 합이 같고 양쪽 모두 더블(트리플)이면 무승부여야 하는데 **플레이어 승리**로 처리 | 테스트 모드 눈 지정 API로 [3,3] vs [3,3]을 만들면 재현. **결정 테이블** 기반 TC와 Selenium 시나리오로 검출 | [BUG-001](05-defects/BUG-001.md) (10/27 검출, TC-B05 FAIL) |

## 일부러 심지 않은 것

- [BUG-004](05-defects/BUG-004.md) (매치 중 주사위 개수 선택이 바뀌어 보임): TC 작성 중 **실제로 발견한 UI 결함**. 고치지 않고 리포트한다.
- [SPEC-002](05-defects/SPEC-002.md) (기간 역전 처리 규칙 없음): 유저 시나리오 작성 중 실제로 발견한 명세 빈틈.

- SPEC-001 (중도 이탈 매치 처리 규칙 없음): 심은 것이 아니라 앱을 만들며 **실제로 발견한 명세의 빈틈**이다. 코드 결함이 아니라 명세 개선 이슈로 리포트한다.

- R-09 (같은 라운드 중복 던지기): `SELECT … FOR UPDATE`와 라운드 번호 검사로 **정상 동작**하게 만들었다. TC-004 동시성 테스트에서 "정상 동작을 부하 상황에서 확인"하는 사례로 쓴다.
